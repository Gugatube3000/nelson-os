# Install prompt

Open **Claude Code** or **Codex** on the computer where Nelson OS should run, paste everything in the box, and press Enter.

```
Please install Nelson OS on this computer for me. I'm not technical, so do every step yourself and only tell me when I need to click something.

The code is here: https://github.com/Gugatube3000/nelson-os

1. Make sure Git and Node.js (version 22 or newer) are installed. Install whatever is missing.
2. Download Nelson OS into a folder called "Nelson OS" in my home folder. If that folder already exists, update it instead.
3. Open the AGENTS.md file in that folder and follow its "Install" section exactly. Don't change any code.
4. When the Nelson OS window opens, walk me through the steps on screen. Stay with me until my AI (Claude or ChatGPT), Procore and Outlook all show as connected.

If anything fails, fix the cause and try again, and tell me in one sentence what you did.
```

What happens:

- Nelson OS is installed and set to start whenever the computer starts.
- A **Nelson OS** icon appears on the desktop.
- Nelson OS becomes available inside Claude and Codex too ("What's overdue on Fulton St?").
- The setup window opens. Connect Claude or ChatGPT (your existing subscription), Procore, and Outlook (read-only). Each is a sign-in and an **Allow** button.
- Nelson OS never sends email and never changes Procore on its own: you send from Outlook, and Procore changes wait for your approval.

To update later, ask Claude or Codex: *"Update Nelson OS."*
